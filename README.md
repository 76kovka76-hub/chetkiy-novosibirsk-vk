# ❄️ Чёткий Новосибирск — бесплатный бот для сообщества ВК

Автономный проект для сообщества [«Чёткий Новосибирск»](https://vk.ru/club243227021), **ID группы: 243227021**. Ярославль, Екатеринбург, Краснодар и другие репозитории не затрагиваются.

## Что делает бот

- До **30 коротких публикаций в сутки** по часовому поясу Новосибирска (`Asia/Novosibirsk`, UTC+7): не чаще одной публикации в 48-минутном слоте.
- GitHub Actions запускается приблизительно каждые пять минут с возможными задержками. Это не гарантия 30 записей.
- Ищет настоящие свежие городские новости из двух бесплатных RSS-подборок Google Новости по Новосибирску, фильтрует новости всей области, устаревшие материалы, повторные URL и похожие заголовки.
- Краткие тексты в разговорном стиле «Братва», «Пацаны», «Народ», **три тематических хэштега** с названием Новосибирска — только читаемые слова без цифр, подчёркиваний и случайных идентификаторов. Теги могут повторяться между постами.
- Когда подходящих новостей нет, публикует мини-игры и вопросы: знакомство, комментарии, фото обеда, обсуждения районов, Академгородок, Красный проспект, Обь и прогулки.
- Интерактивные посты: максимум **четыре за сутки**, не чаще раза в три часа, только с 08:00 до 22:59 местного времени. Одну игру не повторяет семь дней.
- Сохраняет историю постов, URL и хэштегов в `history.json`.
- **Нет платного OpenAI API и платных внешних сервисов**; используется Python стандартной библиотеки и GitHub Actions в публичном репозитории на стандартном раннере в рамках условий GitHub.

## Статус: реальная автоматическая публикация включена

- В [рабочем workflow](https://github.com/76kovka76-hub/chetkiy-novosibirsk-vk/blob/main/.github/workflows/publish.yml) установлено `DRY_RUN: "false"`. Реальные записи могут публиковаться в сообществе ВК.
- [Безопасная проверка](https://github.com/76kovka76-hub/chetkiy-novosibirsk-vk/actions/runs/43257516705): `NOVOSIBIRSK_VK_TOKEN` обнаружен, 19 тестов успешно завершены, обе RSS-ленты доступны.
- **Первая реальная публикация подтверждена:** [пост «Чёткий Новосибирск»](https://vk.com/wall-243227021_1). [Журнал первой отправки](https://github.com/76kovka76-hub/chetkiy-novosibirsk-vk/actions/runs/43257707209).
- История первой публикации сохранена, повторять её бот не будет. **Регулярные запуски по расписанию в течение суток пока не проверены**.
- Чтобы временно остановить постинг, переключите `DRY_RUN` на `"true"` или отключите workflow.

## Настройки для владельца

В репозитории GitHub должен храниться один отдельный секрет `NOVOSIBIRSK_VK_TOKEN` — ключ сообщества ВК №243227021 с правом публиковать на стене. Не передавайте его в чат или в код и не используйте ключи других городов. ID группы уже находится в `main.py`.

Для записи истории GitHub Actions нужны разрешения: **Settings → Actions → General → Workflow permissions → Read and write permissions**.

## Ограничения

- Без ИИ публикации опираются на заголовки RSS и приблизительную фильтрацию; бот не гарантирует независимую проверку каждого факта и отсутствие смысловых дублей.
- Источники Google Новости и GitHub Actions могут временно быть недоступны или запускаться с задержками.
- Система не публикует чужие фотографии; она создаёт текстовые посты, а фото пользователи могут оставлять в комментариях.
- Общий суточный лимит 30, а не обязательное количество.

## Структура

- `main.py` — поиск и фильтрация новостей, VK API, лимиты.
- `engagement.py` — короткие городские вопросы и мини-игры.
- `test_bot.py` — 19 офлайн-тестов.
- `history.json` — история публикаций этого сообщества.
- `.github/workflows/ci.yml` — безопасные проверки.
- `.github/workflows/publish.yml` — автоматическое расписание.
- `.github/workflows/token-check.yml` — безопасная проверка ключа и RSS.
- `.github/workflows/first-post.yml` — однократный первый пост.


## Качество текстовых новостей
- Новости с просьбой смотреть отсутствующие фото, видео, кадры или галереи не публикуются; такие игровые вопросы тоже пропускаются.
- Заголовки с оборванной мыслью, кликбейтом и отсылкой к продолжению отклоняются; факты не додумываются.
- В новостном посте есть законченная мысль, три обычных хэштега и отдельная строка **«Источник:»** со ссылкой на исходный RSS-материал.
- Если качественного материала нет, слот пропускается. Расписание и лимиты не менялись.
- Проверка автоматическая и консервативная; она не заменяет полноценную человеческую смысловую редактуру.
